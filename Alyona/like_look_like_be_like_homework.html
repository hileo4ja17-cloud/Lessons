To sum up

Use this quick guide whenever you are not sure which structure you need.

LIKE

We use like to talk about tastes and preferences.

What does Alex like?
LOOK LIKE

We use look like to describe appearance or physical resemblance.

What does Alex look like?
BE LIKE

We use be like to describe a person's character, personality or behaviour.

What is Alex like?
